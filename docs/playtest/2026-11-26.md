Not yet known whether these are real NPC/driver stalls or the bot retrying the same route. Worth a look by a human.

3. **CPU per draw near its limit.** 21.64 us/draw at the end against a limit of 24.41. The machine was under load (16.2 on 32 cores), so this may be inflated. Recheck on an idle run before reading into it.

## Not covered

The bot checks crashes, page errors, memory growth, frame rate, deaths, driving distance and stuck events. It does not judge gameplay feel, difficulty, mission design, or art. Those need a human playing.

## Suggestions

- Look at the stuck-event trace in minutes 8–14 (which entity and location) to decide whether it is a game bug or a bot routing issue. Logging the position of each stuck event would make the next run decisive.
- Rerun the soak on an idle machine to separate real CPU cost from load noise.
- Raise the inotify `max_user_watches` on the host or run the soak without the Vite watcher, to silence the ENOSPC spam.
