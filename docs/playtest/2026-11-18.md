## Not covered

## Suggestions

- **Soak should fail early with a clear message when baked tiles are missing.** Check that `public/tiles/<city>/index.json` exists before the run and say so in the output. This would turn finding 1 into an obvious setup error.
- **Decide whether the nightly job should bake or fetch tiles.** Either the nightly clone runs a bake or fetch step, or the soak is skipped for clones without tiles. Baking needs the `tools/pipeline` network downloads, so this is a design call for Murphy.
