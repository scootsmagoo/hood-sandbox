## Findings

1. **Soak fails on a fresh clone because baked tiles are missing (FAIL, not a game regression).**
   Log: `hood-playtest-2026-11-24.log`
   - `the bot failed: SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON`
   - `1 page error(s): pageerror: Unexpected token '<', "<!doctype "... is not valid JSON`
   - `the bot drove only 0 m/min (stuck?)`

   Cause (inferred, then confirmed): `public/tiles/` is gitignored and is absent from a clean clone. The dev server answers the tile request with the SPA `index.html`, and the JSON parse fails. With the tiles copied in, the same soak passes. The controls script already checks for baked tiles and skips. The soak does not, so it fails with a confusing message.
   Suggestion: make `scripts/soak.mjs` do the same "no baked tile: skipping" check as `controls-check.mjs`, or fail with a clear "run the bake first" message. Also note in `docs/deploy.md` or the README that a fresh clone needs `npm run bake:m2` (or a copy of `public/tiles/`) before the soak and controls checks. I did not change code in this PR, because choosing between skip and fail changes what the verdict means.

2. **File-watcher limit reached on the host (environment, not the game).**
   Log lines: `file watcher error: ENOSPC: System limit for number of file watchers reached, watch '...'`
   Count: 806 in the fresh-clone soak log, 2643 in the with-tiles soak log, and 806 in the controls log. The host `fs.inotify.max_user_watches` is 524288, so the limit is being hit by many watchers at once. Raising it needs sudo, which murphy does not have. The file-watcher errors did not affect the gate results.

3. **Stuck counter and one sim spike in the with-tiles soak (watch, not a failure).**
   - The bot's `stuck` counter reached 21 by 15 min (943 m walked, 11 cycles). Stuck events occurred from about 1 min on.
   - One sim-step spike: `sim step max 50.87 ms` at 1.75 min. The next highest was 11.74 ms. Frame p50 and p95 stayed at 16.67 ms with 0 slow frames.
   - No `error`, `Uncaught`, or `FAIL` lines in the with-tiles soak or controls logs.

4. **Frame cost drift in the no-tile soak (17.83 to 29.33 us/draw) is noise.** The with-tiles run went 22.07 to 16.74 us/draw. Neither run shows a trend.

Grep for `error|Uncaught|FAIL|warn|stuck` found no failing unit tests. `npm test` had no failures.
