## Findings

1. **Soak could not drive the game (blocker for the soak gate).**
   - Log line: `the bot failed: SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON`, plus `1 page error(s)`.
   - Cause: `src/main.ts:44` sets `DEFAULT_TILE = 'tiles/atlanta/m1-five-points/'`. That folder is baked build output in `public/tiles/` and is gitignored, so a fresh clone does not have it. The dev server answered the `tile.json` request with `index.html`, and the JSON parse failed.
   - Effect: 0 m driven in 15 minutes. The soak did not exercise driving, streaming or the city.
   - Note: `docs/deploy.md` says to bake first (`cd tools/pipeline && npm run bake`). The nightly does not bake.

2. **Controls skipped the real-tile check** for the same reason (`(no baked tile in public/tiles: skipping the real-tile check)`). The 157 passing checks cover the procedural ground only. Tests `realNav.test.ts` and the `public/tiles` parking test are among the 38 skipped tests.

3. **Environment noise, not a game finding.** The soak log has 807 `ENOSPC: System limit for number of file watchers reached` lines from the Vite dev server. The host's inotify watch limit was exhausted. The run finished anyway. Fix belongs to the host (`fs.inotify.max_user_watches`) or to running soak with `--dist`.

- Add a `--dist` soak run so the file-watcher limit does not apply.
