## Findings

1. **Soak bot cannot load its map in a fresh clone (blocker for the soak gate).** Log line 68: `the bot failed: SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON`. Log line 69: `1 page error(s): pageerror: Unexpected token '<'...`. Cause: `scripts/lib/page.mjs` line 47 fetches `tiles/atlanta/m1-five-points/roads.json`. `public/tiles/` is gitignored build output (`.gitignore`: "regenerate with: cd tools/pipeline && npm run bake"), so the file is absent here. The dev server falls back to index.html, and the JSON parse fails.
2. **Controls police-escalation check was skipped, not run.** Controls log: `(no baked tile in public/tiles: skipping)`. The same root cause as finding 1. The overall controls verdict PASS covers only the checks that ran.
3. **Soak reported "driven 0 m/min (stuck?)" as a consequence of finding 1.** This is not evidence of a drive-stuck bug in the game. It is the bot never starting.

No console errors, "Uncaught" errors, or `stuck` events appeared in the controls log. The controls log has no FAIL lines.
