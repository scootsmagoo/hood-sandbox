## Findings

1. **Soak FAIL: baked map tile missing from fresh clone (likely cause).** The soak bot received an HTML page where it expected JSON, and the run failed. `public/tiles/` is gitignored and absent in a fresh clone (`.gitignore`: "baked map tiles (regenerate with: cd tools/pipeline && npm run bake)"). Log line: `the bot failed: SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON`. This run did not regenerate the tile. The bake calls public OSM mirrors and needs the pipeline's own dependencies, so it was not attempted in this nightly. Needs a decision: either bake the tile in the nightly before the soak, or keep the tile as a documented prerequisite.
2. **Controls passed, but two sections were skipped for the same reason.** Log lines: `(no baked tile in public/tiles: skipping the real-tile check)` (line 128) and `(no baked tile in public/tiles: skipping)` under the `=== police escalation ===` header (line 160). The 157 PASS lines do not cover real-tile behaviour.
3. **Machine load during soak.** Log line: `warning: the machine is busy (load 17.4 on 32 cores): timings run high; counts are exact.` Timings from this run should be treated as high-side.
4. **Test skips (informational).** 7 test files and 38 tests are skipped in `npm test`. Likely the real-tile tests (e.g. `src/client/nav/realNav.test.ts` skips when no baked tile is present). Same root cause as finding 1.
